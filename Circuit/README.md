# Circuit Diagram

## Simulation Circuit

The circuit diagram shown here represents the simulated version of the Driver Monitoring and Accident Prevention System.

### Simulation Note

In the simulation, a push button is used as a substitute for the IR/eye sensor because the required eye sensor was not available in the simulation environment.

The push button simulates the digital output of the sensor, allowing the complete drowsiness detection and accident-prevention logic to be tested.

### Actual System Concept

Eye/IR Sensor → Arduino Uno → Drowsiness Detection → Motor Control + Buzzer + LEDs + LCD

### Simulation

Push Button → Arduino Uno → Drowsiness Detection → Motor Control + Buzzer + LEDs + LCD
